# Changelog
All notable changes to WhisperType Android are documented in this file.
The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.
## [1.0.0] - 2026-09-06
### Added
- Floating mic bubble with recording pill, live waveform, Done/Cancel.
- Gemini Live transcription (gemini-3.5-transcribe-live) with server-side smart shaping; insertion at cursor.
- Bluetooth headset mic option, hardware hotkey, auto-stop, custom dictionary, encrypted history, dark mode.
